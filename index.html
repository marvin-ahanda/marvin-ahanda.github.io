Systèmes livrés

Ce qui est en production est marqué PROD. Ce qui est un prototype est marqué POC. Je ne fais pas passer l'un pour l'autre.

Syndic immobilier — Belgique

PROD
Problème

~160 e-mails/jour triés et traités à la main.

Architecture

13 agents orchestrés sous n8n, routage par intention, function calling sur l'API Claude.

Résultat

60 h/mois économisées. Livré en 7 jours. En production.

Agent service client WhatsApp

PROD
Problème

~200 demandes par jour, réponses et réservations manuelles.

Architecture

WhatsApp Business API + RAG sur données réelles + écriture directe dans le CRM.

Résultat

80 % des conversations automatisées, 120 réservations déclenchées.

Agent vocal de prospection

PROD
Problème

La même information répétée à la voix, appel après appel.

Architecture

Vapi.ai + Twilio + API Claude, function calling vers le CRM.

Résultat

25 appels/jour traités, 80 % de taux de contact.
